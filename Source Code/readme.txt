The following are the Jupyter Notebooks detailing our EDA, Feature Processing, Model Training & Optimization and validation steps.1) Data_Preprocessing.ipynb --> EDA and Feature Processing to generate train and test dataset.2) Synthetic_Data_Generation.ipynb --> Synthetic data generation experiment to enhance dataset3) LightGBM_Training_and_Optimization.ipynb --> Model training & hyperparameter tuning for LightGBM model.4) CatBoost_Training_and_Optimization.ipynb --> Model training & hyperparameter tuning for CatBoost model.5) Non_NN_Models_with_Best_Params.ipynb --> Collated notebook of all non-NN models we experimented with and validation with test dataset.6) NN_Hyperparameter_Tuning.ipynb --> Model training & hyperparameter tuning for Neural Network model variations.7) NN_Models.ipynb --> Model training for Neural Network model variations.
